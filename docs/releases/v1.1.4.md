# RootSeeker v1.1.4

v1.1.3 之后的小版本：修复 GitHub README **截图版面撑破 / 徽章异常** 的展示问题。

## 原因

- 界面预览截图原始分辨率为 **1440×900**，表格中的 `<img>` 未限制宽度，在 GitHub README 中会按原尺寸渲染，页面横向被撑开（俗称「图片爆了」）。
- 求 Star 的 shields 徽章 URL 含 emoji（`⭐`），部分环境下徽章无法正常加载。

## 修复

- 为所有预览截图增加 `width`（双列 420 / 通栏 640），并为表格列设置宽度
- Star 徽章改为纯文本 `Star_on_GitHub` / `Star_on_Gitee`，去掉 URL 中的 emoji
- README 版本徽标与发布说明链接同步到 `v1.1.4`

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.1.4
```

本版本仅为文档 / README 展示修复，**无需**重建服务容器。
