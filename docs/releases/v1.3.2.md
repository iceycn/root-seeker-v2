# RootSeeker v1.3.2

v1.3.1 之后的小版本：Admin 增加**宣传首页**，登录成功后首先进入该页，用卡片展示项目介绍、技术选型、联系信息与更新日志。

## 亮点

- **登录后先看首页**：成功登录或已登录访问 `/login` 时进入 `http://localhost:8010/`
- **项目介绍卡片**：含 GitHub 与码云（Gitee）仓库超链接
- **技术选型 / 联系信息 / 更新日志**：分别以卡片展示
- 控制台入口为首页上的「进入控制台」，或 `/admin` / `/overview`

## 本版本主要变更

### Admin / UI

- 新增 `HomePage`：根路径 `/` 渲染宣传页；未登录访问 `/` 会跳到 `/login`
- 登录 / 首次引导成功后默认跳转 `/`，不再直接进入总览
- 侧栏增加「首页」，可返回宣传页

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.3.2
```

从既有 Compose 栈升级时，需要重建 Admin（含前端）：

```powershell
docker compose build --pull=false admin
docker compose up -d --force-recreate --no-deps admin
```

打开首页后请 **Ctrl+F5** 强制刷新，避免继续使用浏览器缓存的旧 JS。

| 服务 | 地址 |
| --- | --- |
| 宣传首页 | http://localhost:8010/ |
| Admin 控制台 | http://localhost:8010/admin |
| API | http://localhost:8000 |
