# RootSeeker v1.2.1

v1.2.0 之后的小版本：把消息模板里的 **条件块写法** 做成和「可用变量说明」相同的表格，避免 `{{#var}}` / `{{/var}}` 难以理解。

## 亮点

- **条件块说明表**：Admin「消息模板」页新增「条件块写法」卡片，结构与「可用变量说明」一致（写法 / 说明）
- **成对含义写清**：`{{#变量}}` 是开始、`{{/变量}}` 是结束，必须成对；单独写无效
- **示例行**：用 `{{#service}}服务：{{service}}` + `{{/service}}` 展示「有值输出整行、没值整段删除」

## 本版本主要变更

### Admin / UI

- 「可用变量说明」只保留变量表
- 新增「条件块写法」表：`{{变量}}`、`{{#变量}}`、`{{/变量}}`、示例
- 编辑模板正文时的提示指向这两张表

### 渲染器

- 行为不变：仍支持 `{{var}}` 替换与 `{{#var}}...{{/var}}` 条件块
- 代码注释补充成对标签的含义，避免把 `#` 和 `/` 理解成两种独立前缀

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.2.1
```

从既有 Compose 栈升级时，需要重建 Admin（含前端）：

```powershell
docker compose build --pull=false admin
docker compose up -d --force-recreate --no-deps admin
```

打开消息模板页后请 **Ctrl+F5** 强制刷新，避免继续使用浏览器缓存的旧 JS。

| 服务 | 地址 |
| --- | --- |
| API | http://localhost:8000 |
| Admin | http://localhost:8010/admin |
| 消息模板 | http://localhost:8010/message-templates |
