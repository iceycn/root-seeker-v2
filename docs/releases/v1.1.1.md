# RootSeeker v1.1.1

v1.1.0 之后的小版本：补齐 **可配置消息通知模板**，并修复通知渠道编辑时误清空加签密钥的问题。

## 亮点

- **消息模板菜单**：系统模板可改不可删；普通模板可增删改，并标明可用变量
- **渠道绑定模板**：通知渠道可选择模板；发送时按渠道渲染（未选则回退系统默认）
- **变量填充**：从 Case / Report 组装 `headline` / `problem` / `service` / `cause` 等上下文后填充模板
- **密钥保留修复**：编辑渠道时「加签密钥」留空不再清空已有 SEC 密钥

## 本版本主要变更

### 消息模板

- 独立 `MessageTemplateStore`（file / sqlite / mysql，跟随存储后端）
- 极简模板语法：`{{var}}` 与 `{{#var}}...{{/var}}` 条件块
- Admin API：`/api/message-templates`；列表附带变量目录
- Admin UI：侧栏「消息模板」；通知渠道表单增加「消息模板」选择

### 通知发送

- `build_notify_context` + 按渠道模板渲染广播
- 渠道测试发送走绑定模板 + 样例上下文

### 修复

- 更新通知渠道时空 `secret` 保留原密钥（前后端一致）

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.1.1
```

**Windows**

```powershell
.\setup.ps1      # 国际源
.\setup-cn.ps1   # 国内加速
```

从既有 Compose 栈升级时，建议重建 Admin（含前端）：

```powershell
docker compose build --pull=false admin
docker compose up -d --force-recreate --no-deps admin
```

| 服务 | 地址 |
| --- | --- |
| API | http://localhost:8000 |
| Admin | http://localhost:8010/admin |
| 消息模板 | http://localhost:8010/message-templates |
| 通知渠道 | http://localhost:8010/notification-channels |
