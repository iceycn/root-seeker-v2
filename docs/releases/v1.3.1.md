# RootSeeker v1.3.1

v1.3.0 之后的补丁：修复 GitHub Publish **双推阿里云 ACR** 被拒绝的问题。

## 原因

`docker/build-push-action` 默认附带 OCI provenance / SBOM（`application/vnd.oci.empty.v1+json`）。个人版 ACR 不接受该 manifest，推送 `root-seeker:latest` 时报 `denied: unknown manifest class`。Docker Hub 与 ACR 登录本身是成功的。

## 修复

- Buildx 只推 Docker Hub；再用 `docker pull/tag/push` 镜像到 ACR，避免个人版拒收 `application/vnd.oci.empty.v1+json`
- `provenance: false`、`sbom: false`，以及 `BUILDX_NO_DEFAULT_ATTESTATIONS=1`
- Publish 支持手动 `retag_only`：把已成功的 `latest` 复制成版本号（Hub + ACR），用于 Release 失败后的回填

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.3.1
```

国内继续用预构建镜像：

```powershell
.\setup-cn.ps1 --yes --path docker --storage mysql --pull
```

```bash
./setup-cn.sh --yes --path docker --storage mysql --pull
```

请拉取 tag `v1.3.1` 或 `latest`。v1.3.0 的 GitHub Release 流水线曾失败；ACR 上的 `v1.3.0` 若存在，来自事后回填，请优先使用 `v1.3.1`。
