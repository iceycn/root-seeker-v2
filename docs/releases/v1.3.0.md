# RootSeeker v1.3.0

v1.2.1 之后的功能版本：国内一键安装改为优先拉取 **阿里云 ACR** 预构建镜像；GitHub `Publish` 在推 Docker Hub 的同时双推杭州 ACR。

## 亮点

- **国内加速走 ACR**：`setup-cn.sh` / `setup-cn.ps1`（`ROOTSEEKER_SETUP_REGION=cn`）优先匿名拉取公开仓，失败再回退 DaoCloud / Hub
- **一次构建、两个仓库**：`.github/workflows/publish.yml` 同时打 tag 到 Docker Hub 与 ACR
- **Compose 可覆盖镜像名**：`docker-compose.pull.yml` 使用 `APP_IMAGE` / `ZOEKT_IMAGE` / `GITNEXUS_IMAGE`（不含 tag）

## 本版本主要变更

### 发布

- Hub 镜像仍为 `wuhun0301/rootseeker-v2{,-zoekt,-gitnexus}`
- ACR（命名空间 `root-seeker`）：
  - `crpi-b41zzjy8qjnhgc6o.cn-hangzhou.personal.cr.aliyuncs.com/root-seeker/root-seeker`
  - `…/root-seeker/root-seeker-zoekt`
  - `…/root-seeker/root-seeker-gitnexus`
- GitHub Actions Secrets：`ACR_USERNAME`、`ACR_PASSWORD`（与已有 `DOCKERHUB_*` 并列）。仓库地址写在 workflow 中，无需 Variables

### 安装

- 国内 `start.sh --pull` 不再强制 `DOCKERHUB_USER`
- MySQL / Qdrant / Jaeger 仍走公共镜像加速，不进入 ACR

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.3.0
```

国内推荐用预构建镜像（ACR 仓库须为公开）：

```powershell
.\setup-cn.ps1 --yes --path docker --storage mysql --pull
```

```bash
./setup-cn.sh --yes --path docker --storage mysql --pull
# 或
ROOTSEEKER_SETUP_REGION=cn ./start.sh --pull
```

国际用户继续：

```bash
DOCKERHUB_USER=wuhun0301 ./start.sh --pull
```

从既有本地 build 栈改为拉预构建镜像时，使用上面的 `--pull` 即可，无需再 `compose build`。
