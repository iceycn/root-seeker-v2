# RootSeeker v1.1.3

v1.1.2 之后的小版本：修复 Admin **错误排查失败仍报成功** 的问题，并同步 README（求 Star、工作原理）与本地忽略规则。

## 亮点

- **错误排查真实失败态**：Case 失败时接口返回 `ok=false`，checkpoint 写入真实 `failed`，不再写死 `completed`
- **前端提示对齐**：失败时提示「排查流程已结束，但 Case 未成功完成」
- **README 更新**：补充显眼的 Star 号召；「工作原理」对齐最新 AttemptRunner / Agent playbook 路径

## 本版本主要变更

### Admin / 错误排查

- `_save_default_flow_checkpoint` 按 `case.status` 落盘
- `submit_error_chat` 按 Case / Agent 结果返回 `ok`
- 前端按 `ok` / `case.status` 区分成功与失败提示
- 单测覆盖失败路径与 checkpoint 状态

### 文档与仓库卫生

- README 求 Star（GitHub / Gitee）
- README「工作原理」改为 Agent 工具规划 + 报告后自动通知（YAML 步进已删除）
- `.gitignore` 忽略本地 `.superpowers/sdd/`，并从版本库移除已跟踪的 SDD 草稿

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.1.3
```

**Windows**

```powershell
.\setup.ps1      # 国际源
.\setup-cn.ps1   # 国内加速
```

从既有 Compose 栈升级时，建议重建 Admin（含前端）：

```powershell
docker compose build --pull=false admin
docker compose up -d --force-recreate --no-deps admin
```

| 服务 | 地址 |
| --- | --- |
| API | http://localhost:8000 |
| Admin | http://localhost:8010/admin |
| 错误排查 | http://localhost:8010/error-chat |
