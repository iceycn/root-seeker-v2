# RootSeeker v1.1.2

v1.1.1 之后的小版本：从 Admin 控制台 **下线语义搜索页面与相关入口**，并润色 README，使产品介绍与当前控制台能力一致。

## 亮点

- **Admin 不再暴露语义搜索页**：移除菜单、路由与页面，避免运维控制台提供独立试搜入口
- **清理 Admin 专用 API**：删除 `POST /api/code/semantic-search` 与 `GET /semantic-search` 页面路由
- **文档对齐**：README 版本徽标与能力描述同步到 `v1.1.2`；去掉语义搜索截图与过时表述

## 本版本主要变更

### Admin / UI

- React Admin：移除语义搜索菜单、路由、`pageMeta`、表单状态与页面渲染
- Legacy `admin.html`：移除语义搜索导航与视图
- 删除截图 `docs/screenshots/admin-semantic-search.png`

### Admin API

- 移除 `AdminSemanticSearchRequest`
- 移除 `POST /api/code/semantic-search`
- 移除 SPA 入口中的 `GET /semantic-search`

### 文档

- 更新 `README.md`（版本、能力列表、截图区、发布说明链接）
- 同步 `docs/business-logic/18-apps-api-admin-cli.md` 中 Admin 页面 / API 列表

### 保留（Agent 能力）

以下能力**未移除**，仍供 Flow / MCP / 主 API 使用：

- MCP `code.semantic_search` / `repo.semantic_search`
- 主 API `POST /code/semantic-search`
- Qdrant 语义向量索引

## 升级说明

```bash
git clone https://github.com/iceycn/root-seeker-v2.git
cd root-seeker-v2
git checkout v1.1.2
```

**Windows**

```powershell
.\setup.ps1      # 国际源
.\setup-cn.ps1   # 国内加速
```

从既有 Compose 栈升级时，建议重建 Admin（含前端）：

```powershell
docker compose build --pull=false admin
docker compose up -d --force-recreate --no-deps admin
```

| 服务 | 地址 |
| --- | --- |
| API | http://localhost:8000 |
| Admin | http://localhost:8010/admin |
